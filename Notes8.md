# 🐍 Python Notes 8: Modules

A module is a file containing Python code. It can define functions, classes, and variables.
Modules help us organize code and reuse it.

## 1. Built-in Modules
Python comes with many built-in modules.

```python

# 🐍 Python Notes 8: Modules

A **module** is a Python file `.py` that contains functions, classes, and variables.  
Modules help us split big code into small files and reuse code.

---

## 1. What is a Module?
Any `.py` file is a module.  
Example: `math.py`, `random.py`, `mymodule.py`

---

## 2. Built-in Modules
Python comes with many ready-made modules.

```python
import math

print(math.pi)        # 3.141592653589793
print(math.sqrt(25))  # 5.0
print(math.pow(2, 3)) # 8.0
